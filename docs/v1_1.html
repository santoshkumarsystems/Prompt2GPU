!
Triton JIT event in initial run · 05:02:05 UTC

Just-in-time (JIT) compilation turns a Triton attention-kernel specialization into GPU-executable code when it is first needed. If warm-up did not cover that shape/configuration, compilation during inference can delay the first streamed token.

The private engine log reported kernel_unified_attention compilation in Batch 2 (05:02:05 UTC). Mean client TTFT rose from ~350 ms to ~1,895 ms while TPOT stayed near 28 ms; a warm-server repeat had no new warning. Correlation, not isolated proof of causality. Log timestamp precision: one second; compilation duration was not measured.
